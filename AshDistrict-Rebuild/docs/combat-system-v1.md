# 僵尸与基础战斗系统 v1

## 本版目标

本版建立可继续扩展的即时战斗底层：玩家近战、僵尸感知与追击、攻击前摇、受伤、击退、硬直、死亡和玩家受击保护。角色与僵尸当前使用程序绘制的比例占位形象，后续替换成统一方向的动画序列时，不需要改写战斗判定。

## 玩家操作

- `WASD`：八方向自由移动。
- `Shift`：奔跑。
- `C`：蹲伏。
- 鼠标移动：改变朝向。
- 鼠标左键：近战攻击。
- `E`：开门或搜索。
- `Tab / B`：打开背包。

## 战斗参数

| 项目 | 当前数值 |
| --- | ---: |
| 玩家生命 | 100 |
| 玩家近战距离 | 由当前武器决定；撬棍为 1.35 米 |
| 玩家近战伤害 | 由当前武器决定；撬棍为 34 |
| 单次近战目标 | 1 个，优先命中最近目标 |
| 普通僵尸生命 | 68 |
| 僵尸攻击距离 | 0.82 米 |
| 僵尸单次伤害 | 9 |
| 玩家受击保护 | 0.55 秒 |

近战只命中角色正面扇形范围内、有视线且未死亡的僵尸。一次攻击在动作中段产生一次命中判定，避免按帧重复伤害。攻击距离、伤害、挥动时间和击退由当前装备武器的数据决定。

## 僵尸状态

`闲置 → 游荡 → 追击 → 攻击前摇 → 攻击`。受到打击后进入短暂硬直并被击退；生命归零后进入死亡状态，不再移动、攻击或阻挡目标选择。

僵尸通过近距离感知或视线发现玩家。追击时会检测房屋、围栏、树木等现有地图阻挡，并尝试多个转向角度绕开障碍；相邻僵尸之间保留分离距离，减少重叠穿模。

## 与界面的关系

打开背包、搜索容器或查看战利品时，世界与僵尸不会暂停，玩家仍会受到攻击。搜索进度被攻击后立即中断；背包和战利品页面不会提供无敌效果。玩家死亡后战斗更新停止。HUD 显示玩家生命、受伤提示和命中/击倒反馈。

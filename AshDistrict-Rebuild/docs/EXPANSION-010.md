# 实际扩图 v0.10
## 已实现
- 可行走边界由96×72格扩为512×576格（256×288米）。这仅覆盖1024×1024格小镇总规划的第一部分。
- 现有房屋与道路原坐标保留。旧地图南界的主路已接出，旧东向道路增加转弯连接。
- 住宅区短街、尽端回车位、侧向步道、公园环形步道和池塘。
- 9块未来住宅占地保留为可行走草地。尚未添加新房屋，未把整屋素材当作可进入建筑。
- 地面和新植被按32×32格区块组织；加载玩家附近最多7×7块，离开的区块释放。路线几何与旧核心区常驻。
- 区块使用固定种子生成树草，重访时位置一致；物资/建筑状态的区块持久化尚未实现。
- 树干碰撞数据独立于可见节点，走出加载范围仍正确判定；池塘阻挡行走。
- 地面全局UV保持相位一致；扩大地图后的深度值按统一0.2因子换算，适配CanvasItem层级范围。

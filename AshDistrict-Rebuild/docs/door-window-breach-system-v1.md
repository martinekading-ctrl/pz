# 门窗破坏与翻越系统 v1

版本：0.24

## 玩家交互

- 靠近住宅窗户按 `E` 打开窗户操作页。
- 关闭的窗户可以打开；打开的窗户可以关闭或翻越。
- 玻璃破碎后可以翻越，翻越时有 24% 概率造成手臂或腿部擦伤。
- 窗户存在木板时不能开关或翻越，必须先拆除木板。
- 翻窗使用 0.65 秒的受控跨越轨迹。普通移动碰撞仍然把墙视为实体，避免角色自由穿墙。

## 耐久和维修

- 玻璃基础耐久为 36。
- 每层木板基础耐久为 70，最多两层，外层先承受伤害。
- 门基础耐久为 120；耐久归零后保持可通行的损坏状态。
- 受损木板可以使用木工锤和 1 枚钉子修满。
- 僵尸破坏木板后掉落 1 块可拾取木板，不返还钉子。

## 僵尸行为

- 当玩家与僵尸位于建筑内外两侧时，僵尸比较附近门窗入口并选择代价最低的入口。
- 关闭的门、关闭的窗和木板路障会触发持续攻击。
- 窗户的受击顺序为外层木板、内层木板、玻璃。
- 窗户打开或玻璃破碎后，僵尸执行独立翻窗状态并进入室内。
- 撞门、敲击木板和碎玻璃会产生世界声音，能够惊动附近僵尸。

## 存档

每扇门保存开关进度、耐久和损坏状态；每扇窗保存关闭/打开/破碎状态、玻璃耐久以及各层木板的独立耐久。读取旧版仅含木板层数的存档时，会自动把现有木板恢复为满耐久。

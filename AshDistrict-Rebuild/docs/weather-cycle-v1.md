# 0.32 轻量动态天气

天气系统只负责环境变化，不增加新的生存数值。游戏依次出现晴朗、阴天、雨天和雾天，每个天气时段约六个游戏小时，切换前使用 45 个游戏分钟平滑过渡。现有世界时间已经写入存档，因此读取进度后会自动恢复对应天气，无需增加额外存档字段。

## 画面表现

- 晴朗：保持原有明亮环境色。
- 阴天：降低饱和度并增加轻微冷色覆盖。
- 雨天：使用最多 76 条程序化雨线和轻微暗色覆盖。
- 雾天：使用半透明雾层和四条缓慢移动的雾带。
- 进入建筑后隐藏雨线并降低雾层，避免室内穿透。
- 时间 HUD 旁只显示天气图标和名称，不增加新的面板。

天气不会影响生命、体力、移动、搜索、车辆、僵尸、物品、伤病或服装。效果完全由世界时间确定，画面暂停时天气进度也会停止。

验证命令：`Godot --headless --path . -- --weather-test`。

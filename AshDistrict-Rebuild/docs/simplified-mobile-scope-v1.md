# 简易版 PZ 风格手机生存游戏：范围冻结 v1

## 产品定义

本项目是一款原创的 2.5D 等距视角、横屏、单人离线手机生存游戏。它保留 PZ 类型游戏最有辨识度的体验：进入建筑、搜索物资、躲避或击杀僵尸、处理伤口和生存需求、返回安全屋并保存进度。

目标是做出一块内容完整、操作适合手机、可以稳定游玩的街区，而不是复制 Project Zomboid 的全部地图、物品数量和模拟系统。以后所有版本、完成度与任务优先级都以本文件为准。

## 上线版核心循环

1. 从住宅或安全屋出发。
2. 在连续街区自由行走，进入不同建筑。
3. 搜索食物、水、药品、工具、武器和少量稀有物资。
4. 躲避或击杀室内外僵尸，承担声音、体力和受伤风险。
5. 使用、装备、丢弃或带回物资，进行少量必要制作和修理。
6. 回到安全屋治疗、睡眠、整理背包并自动保存。
7. 退出后从三个本地存档槽继续游戏。

## 上线版固定范围

### 世界与内容

- 只精制当前连续小街区，先以现有 11 栋可进入建筑为内容上限。
- 每栋建筑的外形、入口、房间布局和主要用途不同；家具允许复用模块，但摆放符合现实比例和靠墙规则。
- 保留住宅、便利店、车库或仓储等当前已有类型，不在上线前继续扩建整张城市。
- 保留约 12–20 只活跃僵尸、室内休眠僵尸、尸体搜索和有限镜头外迁入。
- 一处可认领安全屋，一辆可驾驶旅行车，一把基础手枪和少量近战武器。

### 必须完成的系统

- 八方向移动、走跑蹲、等距镜头、碰撞、开门和翻窗。
- 搜索、背包、装备、六格快捷栏、拿取/留下和重量限制。
- 僵尸追击、声音调查、近战、基础枪械、尸体与战利品。
- 时间、饥饿、口渴、体力、疲劳、四部位伤病、治疗、睡眠和死亡。
- 少量制作、窗户加固、武器修理、停水停电与基础家电。
- 四项技能、四种职业、六项特质、四个服装槽。
- 晴天、阴天、雨天和雾天的视觉变化，不附加体温或疾病数值。
- 三个本地存档槽、自动保存、设置、教程和可发布的 Android 包。

### 永久不纳入本项目

- 多人联机与服务器。
- 模组系统和创意工坊兼容。
- 农业、种植、畜牧与动物生态。
- 以完整 PZ 为目标的大地图、海量物品和全系统一比一复刻。

### 上线前冻结，暂不开发

- 高层建筑、地下室和无缝巨型城市。
- 多车型、钥匙、独立车辆部件、拖车与深度维修。
- 多枪种、配件、故障、穿透和复杂弹道。
- 体温、潮湿、疾病、保温和季节模拟。
- 发电机、火灾、自由基地建造与大型制作树。

这些内容不得挤占上线版本的美术、操作、性能和稳定性工作。只有简易版正式发布并完成用户验证后，才重新决定是否增加。

## 手机操作与界面原则

- 左摇杆移动；右摇杆按住瞄准、松手攻击，瞄准和攻击使用同一控件。
- 底部六格快捷栏直接切换武器或使用消耗品，不保留独立“换武”按钮。
- 搜索与背包使用左侧人物、右侧物品的双栏布局；打开页面时世界仍运行，但避免页面遮住危险方向。
- 设置齿轮提供标准、紧凑和左右互换布局；所有主要触控区满足手机误触与安全区要求。
- HUD 只显示生存必需信息，调试标题、地图尺寸和开发状态不进入发布界面。

## 素材与建筑规则

- 采用模块化素材库：墙、门、窗、屋顶、地面和家具可以跨建筑复用。
- 复用素材不等于复用建筑。11 栋建筑必须通过轮廓、朝向、入口、配色、房间和家具组合形成差异。
- 家具按人物和现实空间比例统一缩放；床头、衣柜和橱柜靠墙，桌椅留通行空间，门口不放阻挡物。
- 室外与室内分层渲染，人物进入后屋顶隐藏、近侧墙降低；墙、家具、门窗均使用独立碰撞与遮挡规则。
- 上线前停止扩地图，先消除穿模、重复建筑、占位角色和风格不统一问题。

## 完成定义

达到 1.0 需要同时满足：

- 新玩家可在不看开发说明的情况下完成核心循环。
- 11 栋建筑均可进入、离开和搜索，没有阻断路线或明显穿模。
- 玩家、僵尸、近战和受击使用正式动画与反馈。
- UI、音效、环境素材达到统一风格，发布画面不含调试信息。
- 中低端 Android 真机能够稳定运行，触控、安全区、存档和长时间游玩通过验收。
- 完成崩溃恢复、存档迁移、死亡重开、后台切换和安装包测试。

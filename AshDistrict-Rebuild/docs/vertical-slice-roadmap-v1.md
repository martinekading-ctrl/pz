# 简易手机版上线路线图 v2

## 唯一完成度口径

本项目不再以完整 Project Zomboid 的功能量计算完成度。产品范围已经冻结在 [简易版范围文档](simplified-mobile-scope-v1.md)：单人离线、横屏手机、一个精制连续街区、11 栋可进入建筑和完整的搜索生存循环。

规划图、素材清单、预留字段和单张效果图不计为完成。功能必须进入运行代码并通过测试；美术必须实际接入可玩场景；发布项必须通过真机或安装包验收。

当前 0.32 的简易版上线总进度为 **约 69%**。其中核心玩法系统约 **94%**，已经能够连续游玩，但美术、动画、音频和 Android 发布质量仍未达到上架标准。

## 后续版本顺序

1. **0.33 正式角色与战斗表现**：替换玩家和僵尸占位形象，修正走路、转向、攻击、命中、受击和死亡动画，统一音效与打击反馈。
2. **0.34 11 栋建筑精修**：按建筑规范逐栋调整外形、入口、房间、家具比例、屋顶隐藏和近墙降低，消除穿模与重复感。
3. **0.35 手机 UI 与声音完成**：清理调试 HUD，完成快捷栏、背包搜索、伤病、车辆和设置页面的发布布局，补齐必要环境与交互音频。
4. **0.36 Android 优化与真机包**：中低端设备性能分级、触控安全区、后台恢复、签名导出和多分辨率验收。
5. **0.37 外部试玩与修复**：新手流程、20–30 分钟完整循环、存档迁移、长时间运行和死亡重开测试。
6. **1.0 简易版上线候选**：只处理阻断、崩溃、存档和商店验收问题，不在候选阶段增加新系统。

## 开发冻结规则

- 上线前不再扩大地图，不增加超过现有 11 栋建筑的内容。
- 不开发多人、模组、农业、动物或完整 PZ 级别的系统。
- 高层、地下室、复杂车辆、枪械扩展、体温疾病、发电机、火灾和自由建造全部延后，不占用 0.33–1.0 的开发时间。
- 新建议必须能够改善核心循环、手机操作、视觉质量、性能或稳定性，否则进入上线后的候选清单。

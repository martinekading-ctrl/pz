# 物品与背包 v1

Tab / B 打开或关闭，Esc 返回。左侧人物、预留装备槽和基础状态；右侧 24 格背包、
选中物品详情、使用/丢弃/附近拾回。暗色背景和细边框借鉴战术背包布局，未使用外部游戏素材。

数据与界面暂集中于 scripts/backpack.gd：食物 0.4kg/5件堆叠，水 0.5kg/5件，
绷带 0.1kg/10件，零件 0.25kg/10件。容量 12kg、24格，自动分堆。
搜索拿取只转移装得下的数量，余量仍在原容器。丢弃保存当前位置，1.2米内可拾回。
使用仅消耗一件，状态已满不消耗；基础恢复数值用于后续生存系统接入。

界面期间禁止角色移动/攻击，关闭恢复。装备槽为禁用的明确预留槽，尚无穿戴属性。
此版不含拖拽、多格物品旋转、持久存档或地面掉落图标。地面物品由背包拾回按钮操作。
人物为程序绘制示意，物品目前使用符号图标，后续可替换正式美术。

--backpack-test / --backpack-capture 验证容量、堆叠、使用、满状态不消耗、丢弃拾回与页面锁定。
截图测试临时填入样例物资；正常游戏初始背包保持为空。

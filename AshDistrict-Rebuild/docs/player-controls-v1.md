# 人物与操作 v1

统一参数：`scripts/player_metrics.gd`。地图一格 0.5 米，人物身高约 1.75 米，
碰撞半径 0.25 米。走路 1.6 米/秒，跑步 3.8 米/秒，蹲行 0.75 米/秒。
速度在逻辑地图空间归一化，按屏幕方向操作；沿等距地图轴滑墙。

- WASD / 方向键：移动；停下保持最后朝向。
- 按住 Shift：跑步；按住 C：蹲行，优先于跑步。
- 按住右键：朝向鼠标，允许侧移或后退。
- 左键：0.48 秒挥击动作预演，期间移动速度为当前姿态的 25%。
- E：开关门、搜索；最大交互距离 1.2 米，容器仍需进入正面操作区。
- 搜索及背包页面锁定移动和挥击。

行走摆臂、腿部交替和身体起伏由实际移动距离驱动，撞墙停止踏步。
当前保留程序绘制的人物，仅提供可用动作基线，不是最终人物精灵美术。
挥击尚无伤害、命中、武器耐久或体力消耗，这些属于后续战斗/生存系统。

验证入口：`--player-test` 检查八方向朝向、30/60/120 Hz 下速度、三种速度及墙体扫掠；
`--standard-test` 检查全部交互建筑的入口至家具搜索区可达性及搜索页面。

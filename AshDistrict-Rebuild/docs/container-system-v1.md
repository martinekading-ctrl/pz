# 搜索与容器 v1

靠近物件正面操作区出现轮廓微光，E 开始搜索，Esc 取消。
首次搜索按类型耗时：冰箱 1.5 秒、厨房/衣柜 2 秒、卫生用品 1 秒、工具柜 2.5 秒、杂物 1.2 秒。
完成后标记已搜索，再次查看只需 0.15 秒。取消或离开有效位置不会完成搜索。

搜索页左侧容器、右侧随身背包。支持逐件/整类拿取与放回、一键拿取装得下的物品。
背包仍受 12kg、24格限制；容器容量按类别设置，超限物资不会消失。
每次转移重新验证交互距离；家具选择同时检查墙、门和其他家具遮挡。

规则入口 scripts/container_rules.gd；初始内容沿用 data/building_layouts.json 与
data/residential-placements.json 的每物件 loot 配置，仅在建筑创建时载入。
不做每次打开随机刷新。remaining 与 searched 是后续存档需要保存的字段；
当前只在同一次游戏会话内保留，尚不跨重启。

--container-test / --container-capture：容量截断、数量守恒、放回、重开、
搜索计时、取消、超距转移拒绝、页面锁定；--standard-test：全部11栋建筑搜索回归。

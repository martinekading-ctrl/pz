# 伤病与治疗系统 v1

## 玩法

0.19 将旧版单一的流血值改为头部、躯干、手臂、腿部四个身体区域。玩家点击左上状态卡打开治疗页。页面打开时角色停止接受操作，僵尸和游戏时间仍然运行。

僵尸攻击可能造成擦伤、撕裂伤或咬伤。伤口会产生出血和疼痛；腿伤降低移动速度，手臂伤延长挥击时间并增加攻击体力消耗。咬伤必定感染，感染超过 60% 后持续扣除生命。

## 治疗

- 绷带处理玩家当前选择的部位，每次消耗一个并大幅减缓出血。
- 止痛药缓解约三个游戏小时的疼痛，药效较强时不能重复服用。
- 未感染的擦伤和撕裂伤会随游戏时间恢复，包扎后恢复更快。
- 感染会随时间恶化；包扎只能减慢恶化速度。
- 所有伤口包扎后可以在安全床铺休息，伤口与药效按八小时推进。

止痛药已加入住宅柜体战利品。存档记录每个部位的伤口、包扎、感染和恢复进度，并兼容旧版只有流血值的存档。

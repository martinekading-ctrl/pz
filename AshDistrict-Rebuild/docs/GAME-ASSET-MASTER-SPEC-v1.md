# 《余烬街区》视觉素材总规范 v1.0

本文件是首个可发布版本的视觉素材生成总表，供图像模型、人工美术和接入程序共同使用。目标是制作一套明亮、简洁、现实比例、可扩展的 2.5D 等距生存游戏素材。所有建筑必须能进入，房屋不可用整栋贴图代替。

配套规范：

- 建筑与家具尺度：`docs/BUILDING-STANDARD.md`
- 木墙专项：`docs/WOOD-WALL-ASSET-SPEC-v1.md`
- 植被尺度：`docs/VEGETATION-STANDARD.md`
- 搜索容器：`docs/container-system-v1.md`
- 背包界面：`docs/backpack-v1.md`

## 1. 固定技术框架

| 项目 | 标准 |
|---|---|
| 引擎 | Godot 4.7.2，2D CanvasItem 渲染 |
| 游戏视角 | 2.5D、2:1 等距投影，固定镜头，不使用透视缩短 |
| 基础分辨率 | 1280×720，界面按此分辨率设计并响应式缩放 |
| 默认镜头 | 缩放 0.44；素材必须在较远镜头下仍能看清轮廓 |
| 地图网格 | 1 逻辑格 = 0.5 米；地面投影 64×32 世界像素 |
| 垂直尺度 | 1 米 = 64 世界像素；1.75 米人物约 112 世界像素高 |
| 住宅层高 | 2.7 米；普通门 0.9×2.1 米；窗台高约 0.9 米 |
| 光线 | 柔和白天光，主光来自左上方，阴影朝右下，低至中等对比度 |
| 文件 | PNG、sRGB；独立物体 RGBA，连续材质 RGB/RGBA 均可 |
| 过滤 | 半写实素材使用线性过滤与 mipmap；不做伪像素风 |
| 锚点 | 地面物体统一底部中心；墙挂物中心；门为左下铰链点 |

图像模型无法稳定输出精确像素时，保留最高分辨率原图，不要自行反复缩放。接入阶段统一裁切、缩放、补边、校正 alpha、制作图集与 `.import` 配置。

## 2. 统一美术风格卡

每次生成新素材都必须带上本节，不能只写“生存游戏风格”。

### 2.1 视觉语言

- 半写实 2D 手绘，现实比例，清楚轮廓，中低细节密度。
- 白天环境明亮，草地保持自然绿色；整体略微褪色，但不使用厚重黄褐滤镜。
- 物体形状先于表面细节，缩小后仍能分辨床、冰箱、门、枪械和不同树种。
- 木材显示板缝和少量木纹；金属显示克制的边缘高光；布料柔软、低反射；玻璃为中性灰蓝。
- 边缘不使用粗黑描边；允许 1–2 像素等效的深色接触边和柔和明暗分离。
- 旧化以日常磨损为主：轻微掉漆、污痕、灰尘和细裂纹。不要让所有物体都严重破损。
- 环境杂物只放在能讲清功能的位置，避免铺满碎纸、石块和高频噪点。

### 2.2 固定颜色角色

| 作用 | 建议色 |
|---|---|
| 健康/安全 | `#6FA56F` |
| 饥饿/警告 | `#C5A24B` |
| 水分 | `#5E8FB8` |
| 危险/伤害 | `#B5534F` |
| 交互高亮 | `#D7C270` |
| UI 主背景 | `#18201E`，透明度 92%–96% |
| UI 次背景 | `#27302D` |
| UI 主文字 | `#E7E4D8` |
| 草地主色 | `#667F3E` 至 `#81934D` |
| 原木 | `#7A5A3B` |
| 褪色蓝墙 | `#61788C` |
| 灰白墙 | `#C5C0AE` |

### 2.3 统一禁止项

不要生成：文字、水印、商标、真实品牌、人物陪衬、完整场景背景、地面底板、强烈地面投影、暗角、摄影景深、鱼眼透视、塑料般 3D 高光、粗黑描边、霓虹色、整栋不可拆房屋、整间不可拆室内、贴到画布边缘、被裁断的物体、棋盘格假透明背景。

## 3. 视角与画布类别

| 类别 | 生成视角 | 推荐源画布 | 接入目标 |
|---|---|---:|---:|
| 连续地面/墙/屋顶材质 | 地面为正俯视；墙为正立面 | 1024×1024 | 512×512 可重复纹理 |
| 小型地面物体 | 2:1 等距，透明背景 | 1024×1024 | 128–256 方形画布 |
| 中型家具/街道物体 | 2:1 等距，透明背景 | 1536×1024 | 512×384 以内 |
| 高家具/门/柱 | 正立面或 2:1 等距，透明背景 | 1024×1536 | 256×512 或 384×512 |
| 树木/路灯 | 2:1 等距，透明背景 | 1024×1536 | 512×768 以内 |
| 车辆 | 2:1 等距，透明背景 | 1536×1024 | 768×512 以内 |
| 物品图标 | 轻微等距陈列角，透明背景 | 512×512 或更高 | 64×64 |
| 单帧人物 | 固定等距方向，透明背景 | 每格 256×256 | 每格 192×256 以内 |
| 人物动作表 | 同一角色、同一动作，八方向各占一行 | 8 帧动作优先 2048×2048 候选表 | 接入后重新切为 256×256 等大帧 |
| 特效动画 | 面向镜头或贴地等距 | 每格 256×256 | 4–8 帧图集 |
| UI 装饰/纸娃娃 | 正面或正交 | 1024×1536 | 按界面缩放 |

### 3.1 等距方向命名

- `N`、`NE`、`E`、`SE`、`S`、`SW`、`W`、`NW` 为人物八方向。
- 家具至少提供 `SE` 与 `SW`：`SE` 显示顶部、正面和右侧；`SW` 显示顶部、正面和左侧。
- 完全对称物体可由接入程序镜像；带文字、门把手、灶台旋钮或不对称污损的物体不可直接镜像。
- 墙面只生成正立面材质，由程序映射到两条等距墙轴。
- 门只生成独立门扇，由程序围绕铰链旋转；不要另画“打开状态”。

## 4. 文件与批次规范

命名格式：`类别_对象_材质或颜色_方向_状态_编号.png`，全部使用小写英文、数字和下划线。

示例：

```text
terrain_grass_lush_01.png
tree_deciduous_green_03.png
furniture_bed_double_wood_se_01.png
door_residential_wood_closed_01.png
character_player_walk_ne_sheet.png
item_bandage_clean.png
fx_blood_hit_01_sheet.png
```

建议交付目录：

```text
asset_delivery/
  00_style_reference/
  01_terrain/
  02_vegetation/
  03_building_materials/
  04_doors_windows_roofs/
  05_furniture_residential/
  06_furniture_commercial/
  07_world_props/
  08_vehicles/
  09_characters/

```

每批保留原始提示词、生成日期、模型版本和参考图。颜色变体应由已经通过的母版进行受限编辑，不能重新从零生成结构。

## 6. 植被

植被为透明背景、底部中心落地点、轻微等距视角。不要把大片草地画在植物脚下。树木真实高度 6–8 米，灌木 0.6–1.2 米，草丛 0.1–0.5 米。

| 家族 | 数量 | 源画布 | 变化要求 |
|---|---:|---:|---|
| 绿色落叶树 | 6 | 1024×1536 | 树冠轮廓、树干弯曲和叶色不同 |
| 针叶树 | 4 | 1024×1536 | 高瘦、普通、宽冠、幼树 |
| 枯树 | 2 | 1024×1536 | 无叶但结构完整，不夸张恐怖化 |
| 树桩与倒木 | 4 | 1536×1024 | 2 树桩、2 倒木 |
| 灌木 | 6 | 1024×1024 | 圆形、松散、带细枝等轮廓 |
| 短草簇 | 8 | 1024×1024 | 高度低，颜色细微变化 |
| 高草/野草 | 8 | 1024×1024 | 不能像小树，与人物小腿以下尺度一致 |
| 野花 | 4 | 1024×1024 | 花色克制，每簇不超过两种主色 |
| 农作物 | 6 | 1024×1024 | 幼苗、中期、成熟各可辨认 |

树冠不可带完整地面阴影。统一接触阴影由程序绘制；树冠遮住人物时由 shader 淡化。

电线可由程序连接电线杆，不生成固定长度带背景的整条电线。

## 11. 车辆

首版制作 4 种车辆：紧凑轿车、旅行车、皮卡、厢式货车。每种提供 `NE`、`SE`、`SW`、`NW` 四方向，共 16 张；车身颜色由 shader 或受限编辑扩充。另做 4 张透明损坏覆盖层：碎窗、车门凹陷、锈蚀、血污。

- 源画布：1536×1024，透明背景。
- 现实尺寸：轿车约 4.4×1.8 米，皮卡约 5.2×2.0 米，厢式货车约 5.5×2.1 米。
- 车辆必须保持四方向车轴距、车高、车窗和轮胎位置一致。
- 首版车辆为静态障碍物；不要画司机、地面、车灯光束或强烈投影。

警车、救护车、校车和可驾驶动画属于后续扩展，不计入首版生成批次。

## 12. 玩家角色

先锁定一个成年人角色母版：现实身高 1.75 米，头身比约 1:7，普通体型，深绿色外套、灰黑裤、棕色背包、深色鞋。固定脸型、发型、服装层次、身体宽度和武器手。

每格 256×256、透明背景、底部中心脚底锚点、无地面阴影。所有动作制作八方向；每个动作优先生成一张八行方向表，行顺序固定为 `N/NE/E/SE/S/SW/W/NW`，接入时统一切帧。图像模型无法保持格子时，退回为每方向一条动作条，不把不同动作塞进同一张图。

| 动作 | 帧数 | 建议速度 |
|---|---:|---:|
| idle 呼吸 | 4 | 5 fps |
| walk | 8 | 10 fps |
| run | 8 | 12 fps |
| crouch_walk | 8 | 8 fps |
| shove 推击 | 6 | 12 fps |
| melee_crowbar | 8 | 14 fps，包含预备、命中、收势 |
| pistol_aim | 2 | 输入保持 |
| pistol_fire | 4 | 16 fps，不把枪口火焰烘焙进角色 |
| reload | 8 | 10 fps |
| hit_react | 4 | 12 fps |
| fall_death | 8 | 10 fps |

先做 `S/SE/E/NE` 四个母方向并检查动作，再补其余四方向。不要依赖简单镜像完成持枪和撬棍动作，镜像后武器手必须符合统一设定。

## 13. 僵尸角色

制作 4 个外观母版：普通男性、普通女性、工装僵尸、破损外套僵尸。通过肤色和衣服低幅度变色扩展人群，不能只把完全相同的尸体换颜色。

每个母版需要八方向：idle 4 帧、walk 8 帧、attack 8 帧、hit 4 帧、fall/death 8 帧。另做爬行僵尸 1 个母版：crawl 8 帧、attack 6 帧、death 6 帧。

- 身高保持 1.6–1.85 米范围；姿态可驼背，但不能与树同高。
- 行走重心迟缓，脚步不滑动；攻击先伸手再扑抓。
- 血迹适量，避免全身高频红色噪点；轮廓必须能与玩家快速区分。
- 尸体最终帧可复用为地面尸体，但仍需单独检查碰撞与排序。

## 14. 武器与手持物

独立地面/背包图标：撬棍、棒球棍、斧头、锤子、厨刀、砍刀、手枪、霰弹枪、步枪、手电筒、汽油桶，共 11。源画布 1024×1024 透明，轻微等距陈列角度。

角色手中的撬棍和手枪先烘焙进对应动作母版，以保证手部对齐。后续需要换装时再制作独立武器层；本阶段不要生成无法与人物动作配准的散装手持方向图。

## 19. 给图像模型的固定提示词头

每个资产提示词开头粘贴以下内容，再追加具体对象：

> 用于《余烬街区》的正式 2.5D 等距生存游戏素材。固定 2:1 等距投影，现实比例，半写实 2D 手绘风格，中低细节密度，轮廓清楚，明亮但略有末日旧化的白天环境，柔和左上方主光，低饱和自然色，材质清楚但不过度写实。独立物体使用真实透明背景，完整居中，四周至少保留 8% 透明边距，无地面底板和强烈投影。保持与本批母版相同的镜头、比例、光线、边缘处理和纹理密度。

固定排除词：

> 不要文字、水印、logo、品牌、背景场景、人物陪衬、地面方块、棋盘格假透明、暗角、摄影景深、透视镜头、塑料 3D 高光、粗黑描边、霓虹色、额外物体、重复物体、裁边、整栋房屋贴图、整间房间贴图。

材质类提示词将“2:1 等距投影、透明背景”替换为“正俯视或正立面正交视图、1024×1024、横纵完全无缝平铺、均匀光照、画布完全不透明”。

## 20. 推荐生成顺序

不要一次让模型生成整份清单。每批先交付母版，确认后用母版编辑出同家族变体。

1. **风格锚点 12 张**：玩家站立、僵尸站立、草地、树、蓝木墙、屋顶、门、窗、床、冰箱、轿车、物品图标。
2. **地图基础**：地形材质、地面覆盖层、植被。
3. **建筑外壳**：墙、屋顶、门窗、围栏和外部结构件。
4. **住宅家具**：先完成 H01/H02 能用的核心家具，再扩展其他住宅。
5. **商业家具与室外道具**：便利店、诊所、仓库和街道。
6. **角色动画**：先四个母方向做动作测试，通过后补八方向。
7. **车辆**：4 类车辆四方向及损坏层。
8. **物品和 UI**：先接入现有食物、水、绷带、零件，再扩成 57 个图标。
9. **特效**：战斗手感确定后制作，避免动画节奏返工。

按上述首版范围，环境、建筑、家具、道具、车辆、图标、UI 与特效约需 350 个源文件；其中大量颜色和破损属于母版受限编辑。角色若使用八方向动作表，玩家约 11 张动作表，四类站立僵尸约 20 张动作表，爬行僵尸约 3 张动作表。不要把“文件总数”理解为同样数量的独立创意设计。

## 21. 每批验收标准

- 独立物体有真实 alpha，背景 alpha=0，实心主体应达到 alpha=255，无黑边或白边。
- 有效内容不碰画布，四周至少 8% 安全边距；同家族使用同一地面锚点。
- 连续材质通过 3×3 平铺检查，无接缝、亮边和明显周期性焦点。
- 家具和门窗按现实米制缩放后不穿墙，使用面朝可行走区域。
- 等距物体的地面轴斜率、可见侧面和光线方向一致。
- 人物所有帧身高、头身比、服装、脚底基线和武器手一致；动画无脚滑和体积跳变。
- 图标缩到 64×64 后仍能识别；不同物品不能只靠文字区分。
- UI 在 1280×720 下可读，不把功能文字烘焙到图片中。
- 每张保存来源工具、生成日期、母版引用、提示词和使用限制。
- 通过联系表与实机截图后才标记为正式素材；单张生成效果好看不等于已可接入。

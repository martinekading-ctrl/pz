# 可复用建筑规范 v0.7

本文件为本游戏的设计尺度，不是建筑施工规范。目标：真实比例、清楚入口、能进屋与正面搜索。先规划占地和通行，再制作素材。

运行 tools/validate_buildings.py 可检查几何规则并重新生成平面图；Godot --headless --path . -- --standard-test 检查运行时连通与搜索。

## 统一坐标
- 1 逻辑格 = 0.5 米；平面每米投影为 (64,32) 或 (-64,32) 像素；竖直高度每米 64 像素。
- 家具数据使用房屋本地米制坐标；position_m 为占地左上角，size_m 为地面占地，height_m 为高度。
- 不可用整屋贴图替代可进入建筑。地面、墙、窗、门、屋顶和家具独立。
- 主角目标身高 1.75 米、身体宽 0.5 米。现有角色仍是占位图，最终模型需重新对齐此尺度。

## 布局
- 住宅 6.5 × 5 米，层高目标 2.7 米；便利店 8 × 6 米，层高目标 3 米。
- 床 1.5 × 2 米，床头靠实墙；床尾或侧面留可到达的使用区。
- 衣柜/橱柜背靠墙；冰箱后侧保留间隙。柜门正面不得对着不可达墙角。
- 餐桌周围为椅子与起身留空间；当前桌椅合成素材尚需独立椅子模块。
- 冷柜沿墙成排；中央货架分列；店内主通道目标不小于 1.5 米。
- 收银台顾客侧通向出口，后方保留店员空间。
- 入口应有连续道路、门框、门垫；不得被植物、柜体或停车位挡住。
- 门最终标准：住宅净宽约 1 米，便利店双门总净宽 1.8 米；开门扇区不得摆家具。
- 窗户应与家具避让；床头和高柜背后优先完整实墙。

## 可复用数据
见 data/building_layouts.json：
name / cell / position_m / size_m / height_m / front / wall / clearance_m / loot。
front 表示允许搜索的一侧，wall 表示靠墙的一侧；clearance_m 为正面使用区深度。
新增建筑复制模板、设置尺寸和原点、规划门窗及开门区、填入家具，再执行检查。相同布局数据用于运行时与 docs/layout-plans.html。

## 验收顺序
1. 米制平面图：占地边界、不重叠、背靠墙、使用区净空。
2. 玩家碰撞体从入口到所有操作区均可达；不能背后搜索。
3. 门开启/关闭以及屋顶遮挡实机验收。
4. 素材脚点、朝向、窗户避让、角色比例视觉验收。
5. 上述项目完成后再批准为新建筑模板成品。

# 余烬街区：PZ 地图差距审查与冻结规范 v4

> **历史归档：** 本文记录过去的大型开放世界设想，不再是实施依据。当前开发只执行 `simplified-mobile-scope-v1.md`，上线前不扩图、不制作农业动物、高层地下室或 180 栋建筑。

## 审查结论

v3 还不适合直接进入大规模建筑制作。它解决了设施数量和道路骨架，但缺少地下层、停车与装卸、僵尸和车辆分布、房间与战利品、野外采集、随机故事、跨区域扩展等地图系统数据。若先做美术，后续会因入口、房间、道路和地块尺寸返工。

v4 已把这些会改变地图结构的项目写入总图、地块表和 JSON。现在可以冻结城市骨架并进入 Godot 白盒阶段。这里的“可冻结”只表示结构和数据接口齐全，不表示 180 栋建筑、室内、地下室或美术素材已经制作完成。

## 对照依据

本次以 Project Zomboid 官方公开的 Build 42 地图说明和制图日志为主要对照：

- [Build 42.20 Features Overview](https://projectzomboid.com/blog/features-overview-build-42-20/)：独立建筑、统一街区景观、地下室、高层、随机门灯状态、城市僵尸分布、世界种子、地图边缘和本地车辆。
- [42.20: The Big Glow Up](https://projectzomboid.com/blog/news/2026/07/42-20-the-big-glow-up/)：城镇风格差异、建筑唯一性、建筑层数、地下室和环境覆盖层。
- [BagZ of Fun](https://projectzomboid.com/blog/news/2023/07/bagz-of-fun/)：农田、森林、深林、城镇、动物、停车位、植被和事件等空间分区。
- [Heat of the Night](https://projectzomboid.com/blog/news/2024/09/heat-of-the-night/)：僵尸密度围绕建筑、商业、战利品点、交通堵塞和关键兴趣点配置。
- [Munizipal Buildings](https://projectzomboid.com/blog/news/2021/10/munizipal-buildings/)：建筑入口、屋顶、家具、热力图、商业分区和战利品分布共同参与地图验收。
- [Cellar Door-oid](https://projectzomboid.com/blog/news/2023/10/cellar-door-doid/) 与 [Sky High](https://projectzomboid.com/blog/news/2023/09/sky-high/)：地下空间和多层建筑属于地图结构，不能在平面图完成后临时追加。

本项目不复制 PZ 的地图、建筑或素材。对照目标是同等级的世界组成、探索密度和系统数据完整度。

## v4 已修正的结构问题

| 项目 | v3 风险 | v4 处理 |
|---|---|---|
| 垂直空间 | 只有地面设施和楼层文字，地下室无法落位 | 世界支持 `Z=-2…31`；34 栋建筑预留地下层；高层写入楼梯、电梯和层高范围 |
| 道路用途 | 只有道路中心线和宽度，无法判断车辆与行人行为 | 每条路写入车道、限速、人行道、路边停车、货运、路面与排水属性 |
| 关键交通节点 | 河流、铁路和高速出口只有视觉关系 | 写入 3 座桥、4 个铁路口、1 个信号路口和 1 个高速出口 |
| 停车与后勤 | 大型设施可能完成后才发现无停车或装卸空间 | 每个地块写入停车数量与方式；商业、工业、医院等写入装卸口和后勤入口要求 |
| 非建筑地点 | 公园、墓园、营地等容易被后续建筑占用 | 冻结 8 块保留地：湖泊湿地、公园、运动场、墓园、疏散营地、伐木点、检查站、填埋场 |
| 生活设施 | 缺少部分真实城镇设施 | 补入县监狱、广播站、枪械狩猎店、酒类店、书店、美发店、木材场和垃圾转运站 |
| 地图系统层 | 地块只有建筑类型，无法驱动生存玩法 | 定义房间、战利品、僵尸、车辆、停车、采集、动物、故事、供电供水、行人、招牌、地图揭示、地下室、室内随机状态和季节覆盖 15 个数据层 |
| 跨区扩展 | 只有笼统的边缘出口，扩图时容易接不上 | 冻结 9 个扩展门和方向用途；预留机场、城市、监狱、军事、森林、河流和乡野扩展方向 |

## 已冻结的地图骨架

- 世界范围：1024 × 1024 米；逻辑格 0.5 米；区块 16 × 16 米。
- 区域：9 个；建筑地块：180 个；所有地块具有唯一 ID、布局键和外观签名。
- 道路：31 条，包括 1 条外围高速、2 条城市主干道、15 条次干道、10 条本地街道和 3 条乡道。
- 建筑类别：住宅 74、商业 49、公共 22、工业 19、农业 10、特殊地点 6。
- 可扩展垂直范围：地下 2 层至地上 31 层。
- 建筑地块不会占用道路、湖泊、运动场、墓园、营地和其他冻结保留地。
- 住宅入口不直接连接高速或城市主干道。

以下内容从白盒阶段起不得随意改编号或整体位置：道路中心线、区域边界、保留地、地块 ID、设施类型、扩展门、逻辑格尺寸和地图数据层名称。局部入口、停车位、建筑轮廓可在对应地块边界内调整。

## 尚未制作，但接口已经预留

这些项目仍需要逐块制作和实机验证。它们不应被描述为已经完成：

- 180 栋建筑的真实墙体、房间多边形、门窗、屋顶、楼梯、电梯和地下室。
- 每个房间的容器与战利品表，以及物品在现实位置的摆放。
- 僵尸热力图、车辆刷新区、停车位、动物区、森林与采集区的空间绘制。
- 医院急诊、消防车库、超市后仓、工业装卸区等专用通道。
- 每家商户的名称、招牌、传单、地图标记和本地车辆涂装。
- 街区统一绿化与收入差异，以及门窗、灯光、损坏、污渍、烧毁和季节状态变体。
- 交通堵塞、随机故事、封锁点和临时营地的事件组合。
- 高层建筑的逐层内容、视野遮挡、屋顶切换和分块加载。

## 外围扩展保留

1 公里城镇不应把所有大型区域硬塞在一起。下列内容通过扩展门保留到相邻区域：

- 东侧：机场、密集城市和更大的商业区。
- 南侧：区域监狱、军事基地、封锁线和乡村聚落。
- 西侧：深林、河流、采石或重工业扩展。
- 北侧：更大农田、林区和州际公路延伸。

当前城区保留县级拘留设施和检查站，用于早期玩法；大型监狱与军事基地仍作为独立扩展区制作。

## 白盒验收门槛

每个区按“道路和保留地 → 地块 → 建筑外壳 → 出入口 → 室内房间 → 系统层 → 美术替换”的顺序推进。进入正式美术前必须通过：

1. 玩家与车辆能够沿道路完整通行，桥梁、铁路口和高速出口无断点。
2. 每栋建筑至少有一个清楚可达的主入口；大型设施具备独立后勤或应急入口。
3. 房屋、家具、门窗和走道遵守 0.5 米逻辑格与现实尺度规范，没有穿模和无法到达的容器。
4. 室内外碰撞、寻路、视线、屋顶切换和近侧墙隐藏通过实机测试。
5. 停车、装卸、僵尸、车辆、战利品、采集与故事区域在同一坐标系统内对齐。
6. 多层和地下建筑完成楼梯、电梯、层间遮挡与保存加载测试。

第一批白盒应选择 Z04 西部住宅区、Z05 中央商业区和 Z06 东部学校市政区各一个街块。这样能同时验证住宅、商店、高层、医院或学校三种尺度，及时发现规范问题，再批量铺开。

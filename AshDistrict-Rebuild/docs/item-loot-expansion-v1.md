# 物品与战利品扩充 v1

## 目标

0.26 把搜索从“只增加数字”扩展成可形成选择的补给循环：玩家需要判断食物保质期、伤口感染、武器耐久和背包负重，再决定拿取与使用。

## 投放规则

容器使用确定性规则。同一张地图、同一建筑和同一家具索引始终得到相同补给，方便测试、存档和以后扩图。物资只进入符合生活逻辑的容器，搜索过的容器不会因升级重新补货。

## 易腐简化

首个手机切片采用“全地图同批面包”的统一过期时间，避免为每件食物保存独立时间戳。新游戏约两天半后变质，背包会显示剩余天数或“已变质”。后续需要冰箱供电和独立保质期时，可在不改变物品 ID 的情况下升级数据结构。

## 存档兼容

存档格式升级到 v3，保存战利品规则版本与面包过期时间。v1/v2 存档自动迁移；已搜索容器保持原内容，未搜索容器从当前地图模板补入 0.26 新物品。

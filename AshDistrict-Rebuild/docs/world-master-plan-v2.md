# 余烬街区：开放世界设施总规划 v2

> 本文已由 v4 总规划替代，仅保留为历史记录。当前实施依据为 `data/world-master-v4.json` 与 `docs/pz-map-gap-audit-v4.md`。

v2 修正了 v1 的核心偏差：开放世界的差异不能只靠住宅外形。城镇必须同时具备居住、工作、医疗、教育、治安、消防、购物、餐饮、交通、休闲和基础设施，玩家才能把地图当成真实城镇探索。

v1 保留为历史稿，不再用于后续地图制作。v2 是新的实施底稿。

## 城市核心

中央商业区包含三栋 8、10、12 层写字楼，两栋 7、9 层公寓塔楼，一栋 8 层酒店，以及购物中心、大型超市、百货商场、停车楼、公交总站、银行、药店、餐厅、咖啡馆、酒吧、电影院、健身房、服装店、电器店和五金店。

商业区不能画成同样大小的平房。高层建筑需要独立大堂、电梯厅、楼梯间、办公层或客房层、设备层与屋顶；商场和超市需要卖场、库房、装卸口、员工区和停车区；沿街小店使用窄面宽与后门巷道。

## 医疗、教育与公共服务

东部学校与市政区包含四层综合医院、社区诊所、警察局、消防站、市政厅、法院、图书馆、小学、中学、体育中心、公共泳池、社区中心、教堂、养老院和托儿所。西部住宅区另有药店和托儿所，北部农场有兽医诊所，东南郊区有乡村诊所。

医院必须包含急诊入口、门诊、药房、病房、手术与后勤区域；学校要有教室、办公室、食堂、卫生间、体育区域和多个出入口；警局与消防站要有车辆出口和后勤区。

## 交通、工业与城市运行

东北服务区承担跨区交通补给：加油站、便利店、公路餐馆、快餐店、汽车维修、洗车、卡车服务、汽车旅馆、迷你仓和仓库。

西南工业区包含工厂、仓库、物流中心、货运站、维修车库、冷库、建材场、废车场、燃料库、变电站和净水厂。这些设施提供大型室内空间、车辆路线、高价值工具物资与更高遭遇风险。

## 生活圈

- 西部住宅区：独栋、双拼、低层公寓、街角商店、药店、自助洗衣店和托儿所。
- 南部老城区：联排住宅、低层公寓、老城旅馆、社区食品店、面包店、餐厅、酒吧、邮局、教堂、殡仪馆和当铺。
- 北部农场：农舍、谷仓、粮仓、饲料店、农资店和兽医诊所。
- 西北林区：林间小屋、护林站、游客中心、露营服务站、船屋和维护站。
- 东南郊区：独栋住宅、拖车住宅、迷你仓、露营服务站和乡村诊所。

不同生活圈提供不同搜刮表和任务线。食品、药物、武器、工具、车辆零件、建筑材料和特殊设备不能平均分散到每栋建筑。

## 建筑差异规则

每个建筑地块继续拥有唯一的地块编号、用途、占地轮廓、入口、楼层、屋顶、外墙、窗组、附属结构和室内规划记录。模块可以复用，整栋成品建筑不能复制粘贴。高层、中层、大型公共建筑、工业建筑和住宅分别使用独立模块族。

规划数据必须同时通过以下检查：180 个地块互不重叠、全部位于地图内、道路引用有效、建筑占地不超过地块、布局与外观签名唯一，并且医院、超市、商场、写字楼、学校、警消、市政、公交、水电等核心设施全部存在。

百分比只统计已经进入运行代码并通过测试的玩法。规划图、素材清单、预留字段和单张效果图不计为系统完成。

## 先上线一个街块的范围

第一块选择当前住宅、便利店、道路和公园组成的连续区域。保留 3–5 栋可进入住宅、1 家便利店、一个安全屋候选点和 12–20 只按热力分布的僵尸。玩家需要能完成“离开住宅 → 躲避或击杀 → 搜刮食水和药品 → 返回安全屋 → 保存退出 → 继续游戏”的完整循环。

高层、农业、多人和整张 v4 地图不进入第一切片，接口继续保留。车辆已作为第一切片外的可试玩扩展提前加入。

## 后续版本顺序

1. **0.18 体力、疲劳与声音感知（已完成）**：奔跑和攻击消耗体力，噪声吸引僵尸，蹲伏降低声音。
2. **0.19 伤病与治疗（已完成）**：四个身体部位、擦伤、撕裂伤、咬伤、感染、包扎、止痛和伤势操作惩罚。
3. **0.20 僵尸分布与刷新（已完成）**：按建筑热力生成、室内休眠僵尸、持久尸体搜刮和有限镜头外迁入。
4. **0.21 基础枪械（已完成）**：一把 9mm 手枪、弹匣、装填、瞄准、射击散布、枪声感知和弹药搜刮。
5. **0.22 简单制作与路障（已完成）**：撕布、简易绷带、木板、钉子、锤子、两层封窗、拆除回收和状态保存。
6. **0.23 产品化外壳（已完成 Windows 测试版）**：新游戏、继续游戏、三槽存档、设置、教程、音量控制和 Windows Release；Android 签名与真机验收单独进入后续移动发布阶段。
7. **0.24 门窗破坏与翻越（已完成）**：窗户开关、碎玻璃、玩家与僵尸翻越、逐层路障耐久、维修、破门、噪声与完整存档。
8. **0.25 安全屋、睡眠与自动存档（已完成）**：清屋后认领、床铺睡眠、危险惊醒、进入与退出自动保存、独立自动存档和旧档迁移。
9. **0.26 物品与战利品扩充（已完成）**：8 种功能物品、容器分类掉落、食物变质、消毒与抗生素、武器胶带维修和旧档战利品迁移。
10. **0.27 服装与身体防护（已完成）**：四个穿戴槽、8 件服装、分伤口防护、叠加保护、受击磨损、损坏卸下、分类掉落和完整存档。
11. **0.28 供水、停电与家电（已完成）**：断供时间表、水龙头饮水、空瓶灌装、冰箱断电变质、无电夜间室内和存档迁移。
12. **0.29 幸存者成长（已完成）**：体能、近战、搜索、生存四项行动成长，五级实效加成、技能页和存档迁移。
13. **0.30 首辆可驾驶车辆（已完成）**：旅行车检查页、燃油、加油、后备箱、驾驶碰撞、感染者撞击、手机输入切换和存档迁移。

完成以上系统步骤，并替换玩家、僵尸和首个街块的占位美术后，小区域切片才能进入外部试玩与上架前测试。

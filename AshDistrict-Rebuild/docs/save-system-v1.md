# 本地存档系统 v1

版本 0.16 加入单人本地存档。游戏中按 `F5` 保存到槽位 1，按 `F9` 读取。

存档使用带 `version` 与 `map_schema` 的 JSON 数据，保存玩家位置、游戏时间、生命与饥渴、背包、装备、每件武器耐久、地面物品、建筑门状态、容器内容与已搜索状态，以及当前僵尸位置、生命和警戒状态。保存的是纯数据，不保存 Godot 节点引用。

写入流程先生成 `.tmp`，刷新磁盘后把上一份有效存档复制成 `.bak`，再替换主文件。主文件损坏或解析失败时，读取会自动回退到上一份备份。当前 schema 为 `ash_district_slice_v1`；未来改变数据结构时必须增加迁移步骤，不能直接覆盖版本号。

自动测试：

```text
Godot --headless --path . -- --save-test
```

测试覆盖完整状态往返、容器和门、地面武器耐久、僵尸状态，以及损坏主文件后的备份恢复。

# 余烬街区 · ASH DISTRICT

当前版本为 **0.7：自由住宅区版**，使用 Godot 4.7.2 / GDScript。场景使用精细绘制的废弃街区贴图，人物使用透明四向行走图集；二维导航、脚底碰撞与按深度排序的前景遮挡共同实现立体观感。

## 开始游玩

双击 `build/AshDistrict.exe`，或根目录的 `开始游戏.cmd`。此固定入口已更新为最新自由住宅区版本，无需安装 Godot，无需联网。后续更新使用这个固定入口；其他带后缀的程序为历史交付文件。

开始界面点击“开始探索”或按 Enter。任务是前往青叶便利店，搜索住宅、路口、商店与后巷的容器，累计找到 2 份罐头、2 份饮用水、2 个无线电零件，然后返回绿色圆环标记的安全点，按 E 完成无线电维修。

## 操作

| 按键 | 操作 |
| --- | --- |
| WASD | 相对画面方向移动 |
| 鼠标 | 静止时控制朝向，左键攻击朝向鼠标；移动时身体朝向行进方向 |
| 鼠标左键 / 空格 | 撬棍近战，消耗体力 |
| Shift | 奔跑，声响更容易吸引感染者 |
| C（按住） | 潜行，降低发现距离 |
| E（按住） / 点击附近家具 | 搜索冰箱、橱柜等，需要约 1.4–2.2 秒 |
| E（住宅门 / 侧门附近） | 开关门；关门会同步阻挡人物、寻路和近战 |
| 区域之间 | 直接沿路行走，镜头连续跟随，无需按 E |
| M | 暂停并展开街区路线，点击区域标记目标 |
| 1 / 2 / 3 | 吃罐头 / 喝水 / 使用绷带 |
| Tab | 背包，打开时暂停 |
| Esc | 暂停 / 继续 |
| 鼠标滚轮 | 缩放视角 |
| F5 / F9（游戏中或暂停时） | 保存 / 读取手动存档 |
| Enter（结算界面） | 返回开始界面，重新探索 |

攻击具有方向和距离限制，墙壁会阻挡攻击。连续三次有效撬棍攻击可击倒一名感染者。奔跑和攻击都消耗体力，停下来会恢复。饥饿、口渴随时间下降，归零后缓慢扣血。物资使用后，已完成的搜集任务计数不会倒退。

## 本版内容

住宅区已改为普通地面默认可行走：可以穿过草地、从左右两侧绕屋、进入后院。原房屋和道路从背景中分层绘制，墙、围栏、树干、灌木、车辆和家具分别提供阻挡。前门默认打开，后院侧门默认关闭，靠近按 E 开关；门口有人时不会关门夹住角色。墙面和树冠遮挡玩家时会淡化。

本轮范围是住宅区与区域之间的裸露地面；十字路口、便利店和后巷仍保留原有背景碰撞范围，尚未按住宅区方式重建。未加入翻窗、翻围栏、破坏或建造。

- 四个区域：原住宅与营地、十字路口、青叶便利店、仓库后巷。路口—便利店—后巷构成可往返环路，四条实际连接道路将区域接入同一张 5760×3072 世界地图，没有传送点或换区黑屏。
- Camera2D 跟随与缩放，车辆、墙体与家具的独立前景遮挡。
- 幸存者和感染者各 16 张动画帧：四个斜向，每个方向四帧行走。
- 十三名感染者（距离玩家较远时暂停活动，附近感染者能跨区域追逐）：游荡、发现、沿导航网格绕障碍追逐、近战攻击与击倒。
- 十四处有独立剩余物品状态的容器；四项生存状态、物品背包、地图与任务提示。
- 可搜索家具在靠近时轮廓微微发光，无菱形标识、无整块填色。翻找时显示进度并播放轻微音效。
- 搜索完成打开独立物品页面，逐项点击“拿取”才转入背包；点击“留下”或关闭页面，未取物品仍保存在容器中。挑选时暂停世界，Esc / Enter 或“完成”返回游戏。
- 有剩余物品的容器可直接重新打开；取空后显示“已搜空”。任务收集数量仅在实际拿取时增加。
- 搜索中移动或受伤会中断，未完成的搜索不会发放物品；新增冰箱状态兼容旧版五容器存档。
- 完成与死亡结算、重新开始、带备份的 JSON 存档。
- 本地合成环境风声与交互音效。

这是 2.5D 街区扩展第一阶段：尚未加入开放世界、建造、枪械、联机或动态昼夜照明。原住宅家具绘制在环境贴图内，新商店货架、冰柜、柜台和货箱为独立贴图，都不能搬动或破坏；地图已支持连续行走；连接道路采用重复路面纹理与边缘融合，后续仍可增加沿街建筑和景物细节。当前角色具备按移动距离播放的四向行走、统一帧比例、0.18 秒攻击起手和简化攻击反馈，尚未制作独立受伤、完整近战和倒地动画图集。

## 存档

引擎 `user://` 目录，Windows 通常为 `%APPDATA%/Godot/app_userdata/余烬街区 · ASH DISTRICT/`。

`iso-save.json` 为 2.5D 手动存档，`.bak` 为上一份有效备份；`iso-autosave.json` 为安全点自动记录，和手动存档分开。F9 读取手动存档并在损坏时尝试备份。版本 6 存档另外保存门状态，兼容之前版本；存档包含每个容器剩余物品、区域位置、探索记录和地图目标；兼容版本 2/3 的五/六容器存档，新区域初始物资保留；版本 4 的独立区域坐标在读取时迁移到连续地图位置。兼容此前自动拿取版本，旧版已搜索容器视为已取空，避免重复发放。旧 3D 存档保留，两版互不覆盖。

## 开发与验证

用 Godot 4.7.2 打开 `project.godot`，当前入口为 `iso.tscn`。`scripts/iso/world.gd` 定义导航区域、障碍和前景；`scripts/iso/actor.gd` 处理二维角色与图集动画；`scripts/iso/game.gd` 管理玩法、镜头和存档；`scripts/iso/hud.gd` 绘制中文界面。旧 3D 场景为 `main.tscn`，源码仍保留。

已执行引擎解析、游戏运行、实际渲染截图检查，以及 `--headless -- --smoke-test` 集成检查，覆盖 32 张动画帧、全部搜索点和营地可达性、搜索幂等、消耗品、存读档、非法存档拒绝、近战击倒、胜利与死亡。`--headless -- --walk-test` 通过真实 WASD 输入事件验证玩家从人行道走过入口进入室内；`--headless -- --verify-save` 在新进程中核验测试存档。

导出预设为 Windows Desktop。`.tools/` 保存本机引擎和 Windows 导出模板，不纳入版本管理；在另一台电脑上请安装相同版本模板，并在导出设置中清空自定义模板路径或配置自己的路径。

美术由内置 image_gen 根据用户参考与本项目制作要求生成，原始贴图保存在 `art/isometric/`，规范与提示词说明见 `art/isometric/ART-DIRECTION.md`。字体使用 Noto Sans CJK SC，遵循 SIL Open Font License（见 `art/FONT-LICENSE.txt`）。Godot 采用 MIT 许可（见 `build/GODOT-LICENSE.txt`）。

## 0.6 连续地图验证

所有 14 个搜索点都能从营地在同一张导航网格上到达。四条道路连接住宅、路口、便利店和后巷；出入口传送函数及提示已移除。

- `--district-test`：全部道路和容器可达、物品保留、版本 4 坐标迁移。
- `--district-walk-test`：只注入 WASD，从出生点经过所有道路端点、中段并返回营地；无 E 输入、无测试中的角色坐标重设。测得最大单帧移动约 1.75 像素、镜头位移约 1.75 像素，未出现跳位。
- `--seamless-chase-test`：感染者实际从旧住宅边界追入十字路口。
- `--verify-seamless-save`：新进程恢复地图位置与未拿物品。
- `--smoke-test` / `--search-test`：原有近战、消耗品、胜负、搜索选择与存档回归。
- `--seamless-capture`：输出四条连接道路实机截图。

新增地表美术为 `art/isometric/waste-ground.png` 和 `worn-asphalt.png`，由内置 image_gen 生成，原始提示词见 `SEAMLESS-PROMPTS.json`。区域背景保持原来的等距画风，通过边缘融合接到连续地表。

## 0.7 自由探索验证

`--yard-test` 以真实 WASD 输入绕房屋四周走完整圈，检查草地直穿、多方向到达、墙体/树干/围栏/车辆阻挡，关闭前门后室内外寻路完全隔开，真实 E 键打开侧门，以及门状态保存。`--verify-yard-save` 在新进程恢复门的外观和导航状态。原搜索选择、剩余物品、旧坐标迁移测试通过。`--yard-capture` 输出左侧、后院和侧门实机截图。

新增美术 `art/isometric/yard-props.png` 使用内置 image_gen 生成，完整提示词见 `YARD-PROMPT.json`。原住宅地板、墙面、家具、道路使用原图的独立 UV 多边形；树与围栏改为独立物件。

# 植被规范 v0.9
资源：art/nature/ASSET-SOURCES.md（两套 CC0 素材）。
树木高度约 6–8 米，以竖直每米 64 像素换算。草丛约 0.2–0.35 米，灌木约 0.4–0.7 米。
布局使用固定种子 90210。树木避让道路/铺地 2 米以上、建筑 2.5 米以上，住宅院落内不生成树干。草丛避让铺地和房屋。
树干碰撞半径约 0.21 米；低矮植物不阻挡行走。树木以落地点排序，树冠遮住角色时淡至 28%。
当前地图：36 棵树、226 丛低矮植物。原有草地底纹保留；新增草丛与灌木为独立透明素材。
测试：--standard-capture 包括树干碰撞、禁种区、遮挡淡化、建筑搜索与外墙遮挡回归。

0.9.1：树高以不透明树干底部到树冠顶部计算，排除柔和阴影；落地点使用树干底部像素的中心。角色维持1.75米。

0.9.2：低矮植物分为矮草0.1–0.25米、成簇野草0.25–0.5米、灌木0.6–1.2米；共380丛，疏松分组。所有植物使用不透明底部锚点并缓存。草丛独立着色器提亮绿色，避免重复乘贴图变黑。禁种区和建筑交互回归通过。

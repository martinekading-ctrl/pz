# 物品装备与武器系统 v1

## 装备结构

背包左侧包含主武器、副武器、头部和护甲槽。当前版本开放主、副武器；头部与护甲保留给后续防护系统。点击背包中的武器后，可以选择装备到主武器或副武器；游戏中按 `Q` 在两个已装备槽位之间切换。

武器实例各自保存耐久。丢到地面、重新拾取、放入容器和再次拿出时，原耐久都会保留。只有实际命中僵尸才会消耗耐久，挥空不消耗；耐久归零后武器损坏并从背包与装备槽移除。

## 数据扩展

全部物品与武器参数集中在 `scripts/item_catalog.gd`。新增近战武器只需添加一条包含伤害、距离、挥动时间、击退、耐久、磨损和显示参数的数据，不需要修改攻击判定。

## 验证

```text
Godot --headless --path . -- --weapon-test
Godot --path . -- --weapon-capture
```

自动测试覆盖武器数据、两个装备槽、切换、动态伤害、攻击距离、耐久磨损、损坏移除，以及丢弃和拾取时的耐久保存。截图输出到 `build/weapons-v015.png`。

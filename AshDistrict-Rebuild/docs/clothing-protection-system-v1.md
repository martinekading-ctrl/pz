# 服装与身体防护系统 v1

## 范围

0.27 为手机切片加入四个清晰的穿戴槽：头部、上身、腿部和脚部。穿戴物仍保留在背包中并计入重量，避免增加另一套物品容器操作。

首批服装共 8 件：棒球帽、摩托车头盔、牛仔夹克、皮夹克、牛仔裤、工装裤、运动鞋和工作靴。衣柜是主要来源，部分仓储、商业容器与尸体提供少量补充。

## 防护规则

每件服装分别定义擦伤、撕裂伤和咬伤防护概率。头盔保护头部，外套保护躯干与手臂，裤装和鞋共同保护腿部。多件服装采用独立失败概率组合，防护不会简单相加到 100%。

当前耐久会影响实际防护：耐久越低，基础防护折损越明显。僵尸攻击形成潜在伤口后，系统先判定对应部位的服装防护，再决定是否产生伤口。无论是否挡住伤口，覆盖该部位的服装都会磨损；咬伤造成的磨损最高。耐久归零时物品损坏、从背包移除并自动卸下。

普通攻击生命伤害仍会发生，服装本版只处理皮肤伤口与感染入口，避免一件衣服完全取消僵尸近身攻击的威胁。

## 物品状态

背包显示服装部位、当前耐久以及三类防护率。点击“穿戴”会替换同一部位的服装，点击左侧穿戴槽会脱下。丢弃、拾回、容器转移和存档读取都会保留服装耐久。

## 存档兼容

存档格式升级为 v4，新增四个穿戴槽和逐件服装耐久数组。v1–v3 存档自动迁移为空服装槽；旧档中未搜索容器会按战利品规则版本补入服装，已搜索容器不刷新。

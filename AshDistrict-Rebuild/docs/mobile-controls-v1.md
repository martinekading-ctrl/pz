# 手机操作与自适应 HUD v1

版本 0.17 建立统一输入动作层。角色逻辑只读取移动、瞄准、攻击、奔跑、蹲伏等动作；键盘、鼠标和触屏都通过同一接口提供输入。

## 触屏布局

- 左下摇杆：移动，使用径向死区并保留模拟量速度。
- 右下摇杆：按住拖动瞄准，松手立即朝最后指向攻击；轻点则沿角色当前朝向攻击。每次松手只提交一次攻击请求。
- 交互：开关门或搜索当前物件。
- 跑：按住生效，松开停止。
- 蹲：点击切换。
- 背包：打开现有左右分栏背包。
- 设置齿轮：打开操作设置，可选择标准、紧凑或左右互换布局；选择结果立即保存，下次启动自动恢复。设置界面不暂停游戏。
- 底部快捷栏：六格横排，依次显示主武器、副武器、食物、水、绷带和零件；点击前两格切换武器，消耗品第一次点击选中、再次点击使用。手机界面不再设置独立换武按钮。

所有触摸按钮至少 68×68 设计像素。布局根据视口和系统安全区域重新计算，避开刘海、圆角和底部手势区域。手机界面不再设置独立攻击按钮；背包、搜索、设置或死亡期间会清除摇杆、攻击和奔跑的残留状态。

手机游玩默认镜头缩放为 1.04，使角色、僵尸、门窗与家具显示为上一版的两倍大小。

手机端常驻 HUD 只显示日期时间、生命、饱食、水分、身体状态与底部快捷栏，使用 272×128 的半透明状态卡。快捷栏直接读取背包和装备数据，拾取、消耗、装备切换与武器损坏后会自动刷新。版本标题、操作教程、顶部背包摘要和地图调试信息不进入游玩画面；操作教学由首次进入时的引导承担。

键鼠操作继续保留，用于电脑调试。正常启动显示手机控制层；其他自动测试默认隐藏，`--mobile-test` 验证输入和布局，`--mobile-capture` 生成 `build/mobile-controls-v017.png`。

# 首个可玩街块建筑差异化方案 v1

## 范围

只处理当前运行中的 11 栋可进入建筑：3 栋手工建筑和 8 栋目录住宅。共享墙面、门窗、地板和家具素材，但每栋建筑必须拥有独立轮廓、屋顶、入口、窗户节奏、户型与室内身份。

## 禁止重复的六项

任意两栋建筑不得同时重复以下六项中的四项以上：

1. 建筑外轮廓。
2. 屋顶类型和屋脊方向。
3. 正门位置与进入方向。
4. 正立面窗户数量和节奏。
5. 房间连接拓扑。
6. 室内主色和身份物件。

## 可以复用的内容

- 墙面和地面材质。
- 门、窗、门框、踢脚线和切墙模块。
- 床、冰箱、沙发、柜体、桌椅、卫浴等核心家具。
- 污渍、裂纹、少量杂物和损坏覆盖层。
- 搜索、碰撞、门窗破坏、照明和存档代码。

复用素材时通过正确方向、调色和状态覆盖层适配，不改变现实尺寸，也不把整间房作为一张不可交互的大贴图。

## 制作顺序

1. BlueHouse：完整重构为质量标准，验证室内观感、比例和切墙。
2. ResidentialB01：使用同一素材库做完全不同的两卧平房，验证素材复用不会造成建筑重复。
3. R02 与 R09：拆除重复 H01 模板，分别制作独居平房和工人小屋。
4. R03 与 R08：拆除重复 H02 模板，分别制作家庭住宅和中世纪住宅。
5. R04、R05、R06、R07：完成车库、狭长屋、农舍和 L 形住宅。
6. ConvenienceStore：最后统一商业建筑室内材质与住宅视觉标准。

## 街块完成标准

- 11 栋建筑都能从远镜头凭轮廓和屋顶辨认。
- 进入任何建筑后，入口、房间用途和通行路线能够立即读懂。
- 不出现两栋房屋相同户型仅换颜色的情况。
- 所有可搜索家具都可达，门窗、切墙、碰撞、僵尸进入和存档继续通过测试。
- 默认镜头下整体保持简洁，每个房间 0–3 件小杂物。

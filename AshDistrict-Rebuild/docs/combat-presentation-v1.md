# 0.33 角色与战斗表现

## 目标

本版替换原来只能表示碰撞位置的火柴人外观，让玩家和僵尸的动作能够直接传达当前状态，同时保持程序化角色可以在所有方向、装备和地图位置复用。

## 玩家表现

- 带外套、裤装、鞋、头部、头发、双臂、双腿和背包的完整身体结构。
- 八方向朝向，以及站立、行走、奔跑、蹲伏、瞄准、翻窗、受伤和倒地状态。
- 行走与奔跑使用不同步幅、身体起伏、膝盖弯曲和手臂摆动。
- 近战明确分为前摇、命中和后摇三个阶段；命中阶段显示短暂武器轨迹。
- 手枪射击加入手臂后坐和枪口火光，受伤时产生身体后仰和闪白。

## 僵尸表现

- 四组衣服和裤装配色，保留皮肤、伤口和方向识别。
- 游荡与追击使用不同步幅；追击时身体前倾。
- 攻击拥有蓄力、双臂扑击和收势三个阶段。
- 受到非致命伤害时后仰硬直；死亡后根据个体方向形成两种地面尸体姿态。
- 调查、休眠、翻窗和破坏门窗继续沿用原有 AI 状态并匹配动作。

## 命中反馈

- 近战命中生成一次扩散冲击环与短寿命血点，击倒时数量和持续时间略有增加。
- 玩家受击使用独立颜色的冲击反馈。
- 镜头震动采用快速衰减的 trauma 数值，只改变 Camera2D 的视觉偏移，不移动碰撞体。
- 普通命中、击倒、挥击和玩家受伤使用四个原创短音效；音效由项目脚本确定性生成，不依赖外部版权素材。
- 不使用长时间停帧，保证手机触控连续响应。

## 验证

- `--presentation-test` 验证玩家走跑、近战三阶段、受伤覆盖，僵尸攻击、硬直、死亡，以及命中特效和镜头衰减。
- `--presentation-capture` 生成 `build/combat-presentation-v033.png`，同时展示玩家挥击、僵尸扑击、受击与尸体姿态。

# 0.33.1 实时 3D 玩家、僵尸与车辆

玩家、僵尸和车辆改用实时 MeshInstance3D 模型，不再使用 2D 手绘身体或预渲染人物序列帧。原有等距地图继续使用 2D。

## 接入方式

- 每个对象使用独立透明 SubViewport、正交 Camera3D 和简单灯光。
- 相机俯角与 2:1 等距地面匹配，3D 原点投影精确对齐逻辑对象脚底。
- ViewportTexture 经 Sprite2D 合成，继承原对象深度排序、室内遮挡和昼夜色调。
- 逻辑碰撞、门窗、搜索、攻击判定、驾驶和存档继续由原对象负责。
- 离屏或隐藏对象停用视口渲染；首版适用于当前小街区，尚未完成 Android 真机性能验收。

## 当前模型

- 幸存者：约 1.7 米高，头、躯干、分段手脚、衣物、背包、撬棍及手枪。
- 僵尸：同尺度模型，衣服与皮肤变体，行走、扑击、硬直及倒地姿态。
- 旅行车：约 4.25 × 1.72 米，车身、座舱、玻璃、车柱、轮胎、灯与后视镜；车身转向及车轮旋转。
- 动作目前由节点关节程序驱动，尚非精细蒙皮骨骼动画；当前低多边形外观是可玩初稿。

## 验证与限制

`--live-3d-test` 检查真实模型、透明独立世界、地面锚点、车辆转向、移动状态以及隐藏视口停止渲染。
原移动、近战、车辆、存档及进屋搜索测试也通过。`--presentation-capture` 输出 `build/live-3d-v0331.png`。

后续需要完成模型轮廓和材质精修、武器动作细调、尸体/近墙遮挡视觉验收，以及真实手机 GPU 性能评估。对象间的遮挡仍按 2D 根节点排序，并非整张地图的 3D 深度缓冲。当前阶段不增加完成度百分比。

# 0.33.2 骨骼动画角色

玩家和僵尸由程序关节模型替换为带蒙皮的真实人形骨架。2D 地图、碰撞、战斗和搜索规则仍由原节点负责，角色外观继续通过透明 `SubViewport` 合成到等距地图。

## 动作状态

- 玩家：待机、走路、跑步、持枪待机、持枪走跑、近战挥击、受击、翻越和死亡。
- 僵尸：待机、游荡/追击、攻击、受击、翻越、倒地和睡眠姿态。
- 状态切换使用 0.05 至 0.18 秒交叉淡化；走跑播放速度按实际移动速度调整，攻击片段按游戏判定时长缩放。
- 玩家与僵尸分别保留 43 和 50 根导入骨骼，动作直接驱动蒙皮，不再依赖方块肢体摆动。

## 素材与性能

角色来自 Quaternius Zombie Apocalypse Kit，许可为 CC0。来源记录位于 `art/characters/ASSET-SOURCES.md`。离屏角色继续暂停其独立 3D 视口，维持手机版的渲染预算。

## 验证

`--live-3d-test` 检查骨架、动作片段、走路/攻击切换、地面锚点、车辆朝向和离屏暂停。角色表现截图由 `--presentation-capture` 输出到 `build/skeletal-animation-v0332.png`。

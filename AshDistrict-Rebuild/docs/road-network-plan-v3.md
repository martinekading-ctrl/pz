# 余烬街区：道路与街区规范 v3

> 本文已由 v4 综合规划替代，仅保留为历史记录。当前道路中心线和属性以 `data/world-master-v4.json` 为准。

v3 保留 v2 的开放世界设施配置，重新设计全部道路。旧路网中的不规则环线、过多斜向道路和难以理解的锐角路口停止使用。

## 路网骨架

| 等级 | 数量 | 宽度 | 用途 |
|---|---:|---:|---|
| 高速公路 | 1 | 18 米 | 从东北外围经过，只连接公路服务区 |
| 城市主干道 | 2 | 14 米 | R02 东西主轴与 R03 南北主轴 |
| 次干道 | 15 | 10–11 米 | 连接街区、公共设施和工业区 |
| 本地街道 | 10 | 7–9 米 | 建筑入口、住宅通行和后勤通道 |
| 乡道 | 3 | 8 米 | 湖区与农场低速通行 |
| 合计 | 31 |  |  |

R01 东北州际公路不再穿过城市中心。R08 是唯一高速出口，先进入 R07 服务区前路，再接入城市路网。住宅、学校和医院均不直接开口到高速。

R02 余烬大道水平贯穿全城，R03 中央大道垂直贯穿农场、商业中心和老城区。两条主轴形成唯一的大型十字路口，玩家可快速判断东南西北。

## 分区结构

- 西北林区：R04 湖畔乡道沿湖区边缘缓慢弯曲，并在中央大道结束。
- 北部农场：R05、R06 两条平缓乡道分开农田地块，避免城市道路侵入农场。
- 东北服务区：R07 是横向前路，R08 连接高速出口；内部道路不再画成多边形环路。
- 西部住宅区：两条东西次干道加两条南北支路，形成清楚的六个住宅街块。
- 中央商业区：市场街、车站街、商业西街、商业东街与两条城市主轴组成规则商业网格。
- 东部公共区：校园南北路、医院路和市政路形成公共设施街块，医院与学校均可从两侧撤离。
- 西南工业区：两条宽直工业路连接物流大道，满足货车进出与大型装卸场。
- 南部老城区：三条东西街加两条窄南北街，形成更密集但仍能辨认的旧城街格。
- 东南郊区：南郊连接路承担对外连接，东南郊环路与拖车营地路服务低密度住宅。

## 路口与出入口规则

- 城市路口使用 90° T 字或十字交叉；高速出口允许缓弯。
- 两个路口中心距离原则上不低于 35 米，避免连续碎路口。
- 建筑主入口朝向本地街道或次干道；主干道沿线大型商业需要停车场内部通道。
- 医院急诊、消防车辆、超市装卸和工业货运分别设置后勤入口，不与正门共用狭窄通道。
- 死路末端需要回车空间；道路不能无理由穿过建筑地块、围栏院或水体。
- 人行道沿城市主干道、商业街和公共设施连续铺设；乡道与工业后勤路可不设完整人行道。
- 道路美术按直线、90°弯、T 字、十字、缓弯和高速匝道六类模块制作，接缝必须服从中心线。
